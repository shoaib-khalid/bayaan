# Fonts used locally by the Mushaf reader

- `indopak-v4.2.1.woff2`: Quran Foundation IndoPak Nastaleeq, the same version referenced by the existing reader. Download source: https://verses.quran.foundation/fonts/quran/hafs/nastaleeq/indopak/indopak-nastaleeq-waqf-lazim-v4.2.1.woff2 .
- `jameel-noori-nastaleeq.ttf`: copied from the user's installed Jameel Noori Nastaleeq font for this local project and print preview. Verify the applicable font license before redistributing it publicly.

Fonts are served locally so pagination does not depend on an external font service loading after the first render.
